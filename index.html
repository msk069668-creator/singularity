Make it yours
Fine-grained directives for the compiler.




SING_SECURE("text")
Keep a single string encrypted until the moment it is used.


SING_NO_VM(fn)
Exclude a function from virtualization. Useful for hot paths.


SING_JUNK()
Insert harmless decoy code at this location.


SING_TAMPER_CRASH()
Stop execution when the script has been modified.


SING_RELEASE
A boolean that is true only in protected builds, so development code stays separate.


SING_BUILD_ID
An identifier shared by every use within the same build.
