What every build includes
Each protection is a separate pass you can enable, order and seed.




Virtual machine target
Code is compiled to a custom instruction set with a shuffled opcode table per build.


Control-flow flattening
Blocks are routed through a dispatcher with opaque state transitions.


String and constant encryption
Literals are encrypted at build time and decoded lazily at runtime.


Luau-native output
Handles type annotations, compound assignment and continue statements.


Integrity checks
Optional checks detect modified bytecode and fail in a controlled way.


Deterministic builds
Pin a seed to reproduce an output exactly, or leave it on auto.





One config, one command
Keep protection settings next to your code and run them in CI.


singularity.json
{
  "target": "luau",
  "level": 3,
  "seed": "auto",
  "passes": ["rename", "strings", "flatten", "vm"],
  "integrity": true,
  "exclude": ["public_api.lua"]
}
